ORANO — from saved content to finished actions

ORANO is a cross-platform AI productivity app by Infotik. Save any Reel, video, article, GitHub repo, tweet or PDF, and it produces a summary with grounded key points — then turns actionable saves into projects with ordered task lists. It also generates learning roadmaps and sourced research, and exposes a personal, read-only MCP server so your own AI agent can read your saved context.

What ORANO does well

  • Capture — iOS Share Extension and Android share target; paste a link or upload a local video.
  • Understand — transcripts, captions, visual context and metadata become a concise summary with grounded key points.
  • Plan — actionable sources get ordered task lists with time and cost estimates; reference sources keep useful takeaways without fake checklists.
  • Remember — curated memory facts, a knowledge graph, and per-project chat grounded in what you saved.
  • Hand off — a personal MCP server and REST APIs let your own agents read your context with a personal key (read-only, rate-limited).

Honest boundaries

ORANO is not a bookmark manager (it is action-oriented), not a chat clone, and not open source. The agent integration is read-only today and requires a paid subscription with a manually provisioned personal key. Pricing is a single $5/month subscription.
